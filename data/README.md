# 配布データについて

このディレクトリのCSVには、アプリ本体のコードとは別に、各提供元が指定するライセンス・利用条件が適用されます。

## 川崎市イベントデータ

`kawasaki_events.csv` は、川崎市「川崎市のイベント情報のオープンデータ」を本アプリ向けに改変して利用しています。

- 原データ提供者: 川崎市
- 原データ: [川崎市「イベント情報のオープンデータ化について」](https://www.city.kawasaki.jp/170/page/0000111012.html)
- API: [川崎市イベント情報APIリファレンス](https://eventapp.city.kawasaki.jp/data/api/v1/reference.html)
- ライセンス: [クリエイティブ・コモンズ・ライセンス 表示 2.1 日本](https://creativecommons.org/licenses/by/2.1/jp/)
- 加工内容: 取得期間を実行日から1年間に限定し、座標のないレコードを除外し、複数の開催日を1イベントに統合し、項目名と形式を本アプリ用に変換しています。
- 連絡先の取扱い: リポジトリへの不必要な再掲載を避けるため、メールアドレスと電話番号は生成時に除外しています。申込み・問い合わせの最新情報は、各レコードの公式URLで確認してください。

川崎市は、本アプリの内容、正確性、継続提供を保証または推奨するものではありません。

## とっとりイベントナビ

`tottori_events.csv` には、[とっとりイベントナビのオープンデータ利用条件](https://tottori-eventnavi.jp/opendata)が適用されます。
