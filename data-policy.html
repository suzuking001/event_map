event_map データ収集・掲載方針

最終更新日：2026年7月31日

1．本サービスについて

event_mapは、地域で開催されるイベントを見つけやすくすることを目的として、イベントの開催日時、場所その他の客観的な情報を地図上に整理して提供する個人運営の非公式サービスです。

本サービスは、掲載する施設、企業、自治体およびイベント主催者が提供または運営する公式サービスではありません。

2．使用する情報源

本サービスでは、性質と利用条件が異なる次の情報源を使用します。

  • 浜松市オープンデータ：浜松市が公開する「イベント」データ
  • 地域オープンデータ：大阪府イベント一覧、とっとりイベントナビ、岡崎市イベント一覧、会津若松市のイベント情報、川崎市のイベント情報
  • ウェブ参照情報：イベント主催者、会場、施設等のウェブページや情報掲載ページを参照し、客観的な事実情報を整理したデータ
  • 主催者または権利者から掲載の申込みまたは許諾を受けた情報

浜松市および川崎市データにはCC BY 2.1 日本、大阪府および岡崎市データにはCC BY 4.0、会津若松市データにはクリエイティブ・コモンズ 表示、とっとりイベントナビには同サイトが示す利用条件がそれぞれ適用されます。ウェブ参照情報には、これらのオープンデータライセンスは適用されません。

ウェブ参照情報については、各イベントに参照元URLを表示し、参照元の権利および利用条件に従います。

第三者が運営するまとめサイト、個人ブログその他の非公式な情報は、原則として自動収集の対象としません。

3．掲載する情報

ウェブページから参照する場合は、原則として次の客観的な事実情報に限定します。

  • イベント名称
  • 開催日および開催時間
  • 会場名
  • 所在地
  • 参加料金
  • 対象者または対象年齢
  • 申込みの要否および申込期限
  • 主催者または問い合わせ先となる団体名
  • 公式ウェブページのURL
  • 情報を確認した日時

4．掲載しない情報

明確な再利用ライセンスまたは権利者の許諾がない限り、次の情報は掲載または保存しません。

  • イベントの紹介文、記事本文およびキャッチコピー
  • 写真、イラスト、ポスターおよびバナー
  • 企業、施設または主催者のロゴ
  • ウェブページのスクリーンショット
  • 出演者等のプロフィール文章
  • 個人の携帯電話番号、個人メールアドレスその他必要性の低い個人情報

説明文を表示する場合は、取得元の文章を転載または言い換えるのではなく、客観的な事実情報から本サービス独自の定型文を生成します。

5．参照元情報へのリンク

各イベントには、可能な限り情報参照元の名称およびウェブページへのリンクを表示します。

開催日時、参加条件、中止、延期その他の最新情報については、リンク先の情報をご確認ください。

外部ページは、本サービス内のフレームに埋め込まず、外部サイトとして開きます。

6．情報取得の方法

公式ウェブページを自動確認する場合は、次の方針で運用します。

  • 公開されているページのみを対象とします。
  • ログイン、CAPTCHA、アクセス制限その他の技術的制限を回避しません。
  • robots.txtおよび各サイトの利用条件を確認します。
  • 原則として、同一情報源の確認は1日1回以下とします。
  • 複数ページを確認する場合は、アクセス間隔を設けます。
  • キャッシュや更新日時を利用し、不要な再取得を避けます。
  • HTTP 403または429等が返された場合は、自動取得を停止します。
  • 情報提供元から停止要請を受けた場合は、速やかに停止します。

なお、robots.txtにより取得が禁止されていないことのみをもって、転載または再利用の許可があるとは判断しません。

7．オープンデータ

浜松市オープンデータ「イベント」は、クリエイティブ・コモンズ・ライセンス 表示2.1 日本の条件に従って利用します。

大阪府イベント一覧および岡崎市イベント一覧は、クリエイティブ・コモンズ 表示4.0 国際の条件に従って利用します。

会津若松市のイベント情報は、クリエイティブ・コモンズ 表示の条件に従って利用します。

川崎市のイベント情報のオープンデータは、クリエイティブ・コモンズ 表示2.1 日本の条件に従って利用します。

川崎市データは、本サービスに必要な項目へ抽出・整形し、メールアドレスと電話番号を除外した上で掲載します。申込み・問い合わせの最新情報は、各イベントの公式URLでご確認ください。

とっとりイベントナビのデータは、同サイトが示すオープンデータ利用条件に従って利用します。

出典表示、ライセンス表示および加工した旨の表示が必要な場合は、本サービス上に表示します。

オープンデータに含まれる画像、文章その他の第三者著作物について、別の利用条件が示されている場合は、その条件に従います。

このライセンス表示はウェブ参照情報には及びません。ウェブ参照情報には、それぞれの参照元の権利および利用条件が適用されます。

8．正確性

掲載情報について可能な範囲で確認を行いますが、正確性、完全性および最新性を保証するものではありません。

イベントの参加前に、主催者または会場の公式情報をご確認ください。

9．訂正および削除

主催者、施設、情報提供元または権利者から、掲載情報の訂正、削除または自動取得の停止を求められた場合は、内容を確認したうえで速やかに対応します。

訂正または削除を希望される場合は、次の情報をご連絡ください。

  • 対象となるイベント名
  • event_map上のページまたは表示箇所
  • 公式情報を確認できるURL
  • 希望する対応内容
  • 連絡者とイベントとの関係

問い合わせ先：event_map GitHub Issues（新規依頼を作成）

GitHub Issuesは公開されます。個人の電話番号・メールアドレスなど、公開を希望しない情報は記載しないでください。

10．方針の変更

法令、情報提供元の利用条件またはサービス内容の変更に応じて、本方針を変更することがあります。重要な変更を行った場合は、本ページ上でお知らせします。
